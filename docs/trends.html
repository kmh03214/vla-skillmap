통합형 generalist · π0.7

2026년 4월 논문은 언어 명령 외에 performance metadata와 subgoal image 등 다양한 context conditioning을 학습에 사용합니다. Skill Map을 단일 hard ID로 고정하기보다 목표·전략·결과·시각 evidence를 보존할 이유입니다. π0.7 ↗

통합형이 충분히 강해져도 data provenance와 intervention 기록은 남습니다. 현재 PoC에서는 모델 교체보다 같은 backbone의 공정한 비교부터 진행합니다.

상위 embodied reasoning · ER 2

2026년 7월 공식 설명은 상위 reasoning model이 물리 상황을 이해하고 여러 단계 계획을 만들며 low-level VLA에 motor execution을 넘기는 구조를 명시합니다. Gemini Robotics ER 2 ↗

Model card의 출력은 text입니다. reasoning 성능이나 진행 판정 능력을 motor control·안전 보장의 증거로 해석하지 않습니다. Gemini Robotics ER 2 model card ↗

상위 VLM ↔ VLA 연결의 세 interface

TEXT / BBOX

Language + spatial target

HiVLA는 subtask instruction과 target bounding box를 전달합니다. 명령과 대상 object를 함께 grounding하는 흐름입니다. HiVLA ↗

GOAL IMAGE

Visual subgoal

VISTA는 world model이 생성하는 시각 목표를 사용합니다. geometry를 풍부하게 전달하지만 목표 생성 오류와 계산량을 함께 평가해야 합니다. VISTA ↗

Executable skill call

근거와 제안을 구분합니다.

위 논문들은 서로 다른 데이터·policy·task·평가 조건을 씁니다. 성공률을 한 leaderboard처럼 비교하지 않았습니다. arXiv의 존재와 공개 주장을 확인한 것이며, 독립 재현을 완료한 결과는 아닙니다.

이 연구의 차별점을 만들려면

“cluster에 VLM으로 이름 붙이기”만으로는 LAVLA와 가까워집니다. “kinematics로 skill label을 만들고 conditioning하기”만으로는 AtomicVLA와 가까워집니다. 제안의 핵심은 버전이 고정된 map → annotation budget 선택 → 실제 정책 변화 → failure 수집을 end-to-end로 증명하는 것입니다.

권장 논문 질문

같은 human time·data·compute에서, 모델 내부 evidence를 추가한 Skill Map이 행동 기반 라벨러보다 annotation 비용 또는 continual policy utility를 개선하는가? 성능 개선이 없더라도 라벨 비용 절감은 독립 결과로 보고합니다.
