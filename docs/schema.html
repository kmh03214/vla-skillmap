원본은 그대로.
의미는 sidecar에.

LeRobot v3를 저장·재생의 기준으로 유지하고, Skill Map을 버전이 고정된 annotation 및 telemetry 계층으로 붙입니다. 아래 필드는 이 연구를 위한 제안이며 LeRobot 표준 확장이 아닙니다.

세 종류의 ID를 분리합니다.

SEMANTIC

Skill ID

manipulation.grasp
Ontology에서 안정적으로 유지하는 의미. composite pick의 alias로 사용하지 않습니다.

MODEL-LOCAL

Cluster space + ID

checkpoint / hook / fit hash + c17
모델·표현 공간 안에서만 유효한 evidence.

TEMPORAL

Segment UID

episode UID + segment UID
원본 시간 구간의 annotation. boundary 변경과 label 변경의 revision을 분리합니다.

테이블key / 주요 field검증 규칙

Top-k의 확률 질량

Top-k probs 합이 1보다 작을 수 있습니다. tail_mass와 원래 posterior entropy를 저장하세요. Top-k를 재정규화해서 구한 entropy를 전체 posterior uncertainty와 섞지 않습니다.

부모 composite와 atomic track을 함께 저장하되, 학습에서 사용할 level은 하나의 config로 고정합니다. 두 팔이 다른 skill을 수행하면 track을 나누고 sync relation을 둡니다. unknown은 라벨 상태와 별도의 semantic class로 취급합니다.

01원본 sampledataset index → episode UID / frame index
02sidecar lookup해당 track·level의 half-open segment join
03label adapterskill target / loss mask / source weight
04policy batch기존 observation·action + 선택적 skill target

PoC에서는 Python Dataset wrapper로 join합니다. 검증 후 자주 쓰는 skill_index만 materialize한 새 dataset revision을 만들 수 있습니다. custom field는 feature schema·dtype·shape와 training processor 호환성을 확인해야 합니다.
