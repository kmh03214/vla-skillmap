자가발전의 성숙도

L0수동 map사람 라벨·고정 dataset
L1반자동 annotation자동 제안·사람 검수·audit
L2자동 재학습·평가후보 생성·독립 gate·수동 승격
L3제한적 자동 승격기존 검증 범위·canary·rollback
L4새 skill 후보 확장새 scope를 검증한 뒤 library 확장

자동화의 KPI는 pipeline 실행 횟수가 아니라 새 데이터의 가치, old-skill 유지, 검수 부담, invalid invocation 감소입니다. L2까지는 단기·중기에 달성할 실용적 목표이고, L3–L4는 누적 evidence가 충분한 뒤 진행합니다.

중단해도 남아야 하는 자산

Stellar-specific 실험이 실패해도 immutable dataset registry, gold ontology, annotation revisions, verifier traces, experiment manifest는 계속 사용합니다. representation·router·label teacher는 교체 가능한 모듈로 설계하세요.
