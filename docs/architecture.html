COMPONENT DETAIL

Skill Map / capability registry

의미 ID는 checkpoint보다 오래 유지합니다. cluster↔semantic skill은 many-to-many evidence로 저장하고, 실행 계약은 robot별 executor·calibration·valid scope·verifier·평가 근거를 참조합니다. 새 cluster나 이름만으로 새 실행 기능을 등록하지 않습니다.

Skill Map이 연결하는 세 가지 루프

01 / RUNTIME

실행 → 검증 → 재계획

VLM이 semantic skill을 선택하고 supervisor가 적용 가능성을 검사합니다. VLA는 로컬로 실행하고 verifier의 실제 결과로 다음 행동을 결정합니다.

02 / DATA

실행 로그 → 검수 → map

실패·희귀 skill·불확실성을 선별해 구간과 의미를 검수합니다. 오프라인 전체 clip 라벨과 온라인 과거 관측을 구분해 학습 입력의 미래 누출을 막습니다.

03 / RELEASE

재학습 → 평가 → 승격

고정 snapshot으로 후보를 학습하고, 새 skill 성능과 기존 skill 회귀를 함께 검사합니다. 호환되는 버전 묶음만 canary와 rollback을 거쳐 적용합니다.
