01 / DATA

Semantic map

시간 구간, 객체 역할, skill 의미, 성공·실패를 사람이 검증 가능한 단위로 저장합니다.

02 / RUNTIME

Executable contract

상위 VLM이 호출할 skill의 입력, 실행 가능 조건, 종료·완료 판정, 복구를 명시합니다.

03 / LEARNING

Evaluation ledger

어떤 데이터 선택과 업데이트가 어떤 성능 변화를 만들었는지 기록하고 되돌릴 수 있게 합니다.

VLA를 agent가 사용하는 실행 기능으로 노출하는 방식은 바로 준비할 가치가 있습니다. motor control의 각 frame마다 상위 VLM을 호출하는 구조는 이 PoC의 목표에 맞지 않습니다. 구조화된 skill call과 검증 루프는 Harness VLA ↗ EmbodiedSkills ↗의 접근과 맞닿아 있습니다.
