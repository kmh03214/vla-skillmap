실행 계약을 보완하세요.

포맷 설명의 실제 불일치

LeRobot 공식 v3 문서의 directory 예시는 meta/tasks.jsonl를 표시하지만, 조회한 main 코드의 DEFAULT_TASKS_PATH는 meta/tasks.parquet입니다. 문서 문구만으로 변환하지 말고 설치 commit과 실제 dataset manifest를 기준으로 loader를 선택해야 합니다. LeRobot v3 공식 문서 ↗ LeRobot main / utils.py ↗

연구적으로 추가할 반증 실험

Cluster가 skill을 담는가?

동일 skill에 객체·배경·camera를 바꾸고, 동일 장면에 다른 skill을 실행합니다. task-language 제거와 paraphrase 조건도 비교합니다. Skill F1과 함께 scene/object 예측 성능을 측정해 confound를 확인합니다.

Map이 action을 바꾸는가?

실행 관측과 target을 고정하고 correct·wrong·missing skill 조건을 바꿉니다. 반응성과 성공률을 측정합니다. 잘못된 token으로 실패가 늘면 applicability gate와 unknown fallback을 우선 보완합니다.

평가 결론

계획은 조건부 추진이 적절합니다. 원문의 0–6개월 기반 구축은 feasibility 확인까지 오래 걸립니다. 첫 4주에 annotation utility를 확인하고, 6–8주 안에 소규모 policy utility pilot을 붙여 투자 판단을 앞당기세요.
